# 🚀 DevBlog

A modern blogging platform built for developers — write, discover, and share technical articles with the community.

🌐 **Live:** [devblog.live](https://www.devblog.live)

---

## ✨ Features

- 📝 Write and publish developer-focused blog posts
- 🔖 Save posts and manage drafts
- 🏷️ Discover content by tags
- 👤 Developer profiles with followers & following
- 🔐 Sign in with GitHub or Email
- 🌙 Interactive animated UI

---

## 🛠️ Built With

- **React** — frontend UI
- **Node.js + Express** — backend API
- **PostgreSQL** — database
- **AWS** — cloud infrastructure
- **Vercel** — frontend hosting
